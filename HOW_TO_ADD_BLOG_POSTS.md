# Add or edit a DilSe blog post

1. Open [app.pagescms.org](https://app.pagescms.org) and sign in with GitHub.
2. Choose **mirsamikhan / heart-bridge** and the **main** branch.
3. Open **Blog Posts**, then click **Add** (or **Add new**).
4. Fill in the **Title** and **Publication Date**. Add your name under **Author** and a one- or two-sentence **Short Summary**.
5. For an optional cover photo, use **Cover Image** to upload or select a picture. Pictures in the article can also be uploaded from the editor.
6. Write your post in **Article**. Use the editor buttons for headings, bold text, lists, and links. You do not need to write code.
7. Turn **Draft on** to save without publishing. When the post is ready to go live, turn **Draft off**.
8. Click **Save**.

A published post normally goes live a minute or two after saving, once the website finishes rebuilding. Refresh [the blog](https://mirsamikhan.github.io/heart-bridge/blog/) to see it. If the build takes longer or fails, ask the website administrator to check GitHub Actions.

To edit a post, open **Blog Posts**, select it, make your changes, and click **Save**. Turning Draft on also removes an already-published post after the next successful rebuild. The publication date controls ordering; it does not schedule a future release.

## First-time access

If you cannot see heart-bridge, ask the repository owner to grant your GitHub account access and connect the Pages CMS GitHub app to **heart-bridge**. Never share account passwords. This editor is configured for **Blog Posts** and **Blog Images** only.

## Photos

Use the upload picker instead of typing an image address. It saves photos automatically in the blog image folder. Keep image names unique so replacing a photo does not accidentally change another post.
